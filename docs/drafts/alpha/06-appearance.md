# 06 · NPC 外观要求（像素化规格 v1）

> 用途：像素小人拼装（05 §7）与后续外包/生成立绘的统一美术需求单。
> 风格基准：Kenney oopi 风 Q 版像素——大方头、2px 点眼、1px 描边、粉彩色块；
> 头身比约 2:1，全身 12×16 逻辑像素。
> 配色随圈层递进（03 制作备注）：**职场蓝灰 → 精英藏青 → 名流酒红 → 富豪翡翠 → 顶层黑金**。

## 通用规则

- 发型库 6 种：短发 / 长发 / 丸子头 / 高马尾 / 寸头 / 大背头；配饰库：眼镜 / 耳饰 / 丝巾 / 领带 / 无。
- 服装库 4 种：西装 / 套裙 / 大衣 / 礼服；同一圈层内用点缀色区分类型：
  金钱型=金、声望型=银白、辅助型=青。
- 肤色统一浅暖色 `#F2C9A7`（v1 不做肤色差分）。
