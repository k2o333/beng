# 01 · 系统详设（MVP 四系统）

> 对应总览：NPC / 好感度 / 资源经济 / 个人属性。
> 数值一律见 `02-numbers.md`，本文只定义规则与结构。

---

## 系统 1：NPC

### 1.1 字段定义

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| id | 唯一标识 | `t3_fu_siyuan` |
| 姓名 / 头像 | 内容资源 | 傅司远 |
| 圈层 tier | 1~5 | 3 |
| 类型 type | 金钱型 / 声望型 / 辅助型 | 金钱型 |
| 个体系数 | 0.8~1.5，产出微调 | 1.2 |
| 引荐解锁 | 满级后提前开放的上一层 NPC（可空） | `t4_xie_linzhou` |
| 文案包 | 结识/互动/节点/满级 四组短文案 | 见 03-content |

配置用 JSON 示例：

```json
{
  "id": "t3_fu_siyuan",
  "name": "傅司远",
  "tier": 3,
  "type": "money",
  "coef": 1.2,
  "unlockBy": null,
  "refer": "t4_xie_linzhou"
}
```

### 1.2 NPC 状态机

```text
未结识 ──(圈层开放)──► 可攻略 ──(放入槽位)──► 攻略中
                         ▲                      │ 好感=100
                         │      槽位空出 ◄──────┘
                         ▼                      ▼
                      可攻略 ──────────► 人脉资产(永久产出)
```

- MVP 中同圈层 NPC **全部直接可结识**，不做随机刷新（刻意砍掉，见二期）。
- 人脉资产不可逆、不衰减——本作没有关系恶化惩罚。

### 1.3 攻略槽位

- 初始 3 个；金币扩展至最多 7 个（价格见数值表）。
- 只有**槽内 NPC** 好感自动增长、可互动、可送礼。
- 槽位是操作期的核心决策：先攻略谁、何时换人。

### 1.4 引荐机制（对应 start.md 的"转介绍"）

- 每圈层指定 1 名"社交枢纽"NPC，满级后**无视声望门槛**提前解锁上一圈层的 1 名指定 NPC。
- 作用：给肝帝一条跳过门票的路，也给内容一条叙事线。

## 系统 2：好感度

### 2.1 规则

- 单维数值 0~100，只涨不跌。
- 三个来源：
  1. **自动增长**（放置基本盘）：仅槽内 NPC，速率见公式；
  2. **互动**（手动）：耗体力，即时回一口好感；
  3. **送礼**（花钱）：三档礼物，高圈层 NPC 有档位下限。

### 2.2 节点与转化

| 好感 | 事件 |
| --- | --- |
| 25 / 50 / 75 | 里程碑：发一次性奖励（金或声望）+ 一段剧情短文 |
| 100 | 满级：NPC 移出槽位 → 转为人脉资产，开始持续产出 |

- 满级即"建成投产"，玩家获得明确的完成感 + 槽位空出的取舍感。

### 2.3 离线规则

- 槽内好感按自动速率 ×50% 结算，资产产出 ×100%。
- 结算上限 12 小时（辅助型加成可提高），回归时弹"离线简报"。

## 系统 3：资源与经济

### 3.1 三资源

| 资源 | 定位 | 来源 | 去向 |
| --- | --- | --- | --- |
| 金币 | 主通货 | 资产产出、里程碑 | 礼物、属性、槽位、入场费 |
| 体力 | 手动操作预算 | 时间回复 | 互动 |
| 声望 | 圈层进度通货 | 声望型节点/满级/被动 | 圈层门票 |

### 3.2 经济闭环

```text
        送礼/属性/槽位/入场费(消耗)
              ▲
   攻略投入 ──┘            ┌──► 更强资产
        │                  │
NPC满级 ► 资产产出金币 ──→ 再投入 ──► 更高层NPC
        └──► 声望 ──► 圈层门票 ──┘
```

防通胀手段（MVP 三件套即可）：礼物单价增速(×5) > 收入增速(×2.5)；属性成本指数曲线；槽位天价坑。

## 系统 4：个人属性

| 属性 | 效果 | 成长方式 |
| --- | --- | --- |
| 魅力 | +8%/级 自动好感速度 | 金币升级，成本指数曲线 |
| 谈吐 | +8%/级 互动收益 | 同上 |
| 品味 | 不提供百分比，作为高圈层 NPC 的**硬门槛**与高档礼物解锁条件 | 同上 |

- 属性是金币的第二大去向，也是"职业影响 NPC"的廉价替代：
  **你把自己经营成什么样的人，决定谁能看得上你。**
