# 05 · Bar 形态 UI 规格（桌面通栏版 v1）

> 补齐 00/01 缺口：本作以 **TBH: Task Bar Hero 同款形态**落地——
> 一条常驻桌面底部的像素横条，不占工作区、不打断操作。
> 技术栈：Electron（单机版）。美术：Q 版像素（参考 Kenney "Pixel Platformer" CC0 的 oopi 风格）。

---

## 1. 窗口形态

| 项 | 规格 |
| --- | --- |
| 位置 | 主屏工作区底部，紧贴任务栏上沿，横向铺满工作区宽度 |
| 高度 | 96px（缩放 ×2/×3/×4 时为 72/96/120px） |
| 窗口 | 无边框、置顶（screen-saver 级）、不进任务栏、不可调整大小 |
| 托盘 | 常驻托盘图标：显示/隐藏、退出 |
| 面板 | 点按钮后**窗口向上展开**至 +420px，bar 始终固定在原位；Esc/再点收起 |
| 单实例 | 重复启动时唤起已有窗口 |

## 2. Bar 主条布局（单屏原则的 bar 版）

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 💰1.24万  🏅230  ⚡78/100  收入 3.2/秒 │ ○○●●○ 舞台区(像素小人) │ [攻略][属性][圈层][设置] │
└──────────────────────────────────────────────────────────────────────┘
   左：资源 HUD(固定宽)            中：舞台(弹性宽)           右：功能按钮(固定宽)
```

- **HUD**：金币（万/亿缩写）、声望、体力条、每秒收入。
- **舞台**：槽内 NPC 以像素小人站在跑道上，头顶悬浮 `名字 好感/100` 进度条；
  里程碑/满级时头顶弹事件气泡；人脉资产数量在舞台左端以小徽章展示。
- **按钮**：攻略 / 属性 / 圈层 / 设置，四个入口，全部从这一条 bar 一次点击到达。

## 3. 面板规格（向上展开 420px）

| 面板 | 内容 | 操作 |
| --- | --- | --- |
| 攻略 | 按圈层分组的 NPC 列表；卡片=像素头像+姓名+类型+圈层+好感条+状态 | 入槽/请离、互动(-10⚡)、送礼三档、查看引荐关系 |
| 属性 | 魅力/谈吐/品味 三行：等级、效果、升级成本 | 金币升级 |
| 圈层 | 5 层纵向地图：名称、门槛(声望/入场费/品味)、产出倍率、状态 | 达标者可付入场费进入 |
| 设置 | 缩放、开机自启、离线简报回看、重置存档 | — |
| 离线简报 | 回归弹窗：离开时长、金币/声望收益、好感进度列表 | 点击领取关闭 |

## 4. 反馈系统（回归体验红线）

- 里程碑/满级：舞台头顶气泡 + 面板红点；满级播放"资产上线"金色浮字。
- 所有数值变动：HUD 数字滚动 + 舞台浮字（+4 好感 / +300 金）。
- 圈层跃迁：全 bar 闪金边 2 秒 + 横幅"进入精英圈"。

## 5. 存档与时间

- 存档：`%APPDATA%/renmai-bar/save.json`，10s 自动 + 关键操作即时 + 退出时强制。
- 时间轴：所有结算基于时间戳差值（挂机/休眠/关机重开均正确）。
- 离线结算：启动时按 `lastSeen` 一次结清，上限 12h + 每辅助型资产 +1.5h（封顶 +12h）；
  好感 ×50%，金币与声望被动 ×100%。

## 6. 数值补全（文档未定义处的 v1 决策）

| 项 | v1 取值 | 依据 |
| --- | --- | --- |
| 辅助型全局加成 | 每个辅助型**资产** +5% 自动好感速度，叠加封顶 +50% | 01 公式中的"(1 + 辅助型加成)"未给值 |
| 声望被动归属 | 按资产自身圈层取 02 §4 表值 | — |
| 里程碑归属 | 金钱/辅助型发金币(02 §6)，声望型发声望节点(02 §4) | 两表并列，按类型分流 |
| 大礼品味门槛 | 品味 ≥ ⌈该层门槛/2⌉（T1/T2 为 0） | 02 §5"该层门槛的一半" |
| 礼物档位下限 | v1 以大礼品味门槛替代 01 §2.1 的"高圈层档位下限"，拒收小礼二期再做 | 简化一维好感来源 |
| 体力离线 | 离线期间照常回复（不受 12h 结算上限约束） | 02 §8 未规定，按放置惯例补全 |

## 7. 美术规格（像素）

- 风格基准：Kenney Pixel Platformer（CC0）的 oopi 造型——大方头、2px 点眼、1px 深色描边、粉彩色块。
- NPC 小人：12×16 逻辑像素网格，部件化拼装（发型 6 种 × 服装 4 种 × 配饰），按 NPC 外观要求上色（见 06）。
- 动画：待机 2 帧（呼吸起伏），入场/满级走路 2 帧；缩放 ×2/×3/×4 整数倍渲染，禁用平滑。
- 圈层色调递进：职场蓝灰 → 精英藏青 → 名流酒红 → 富豪翡翠 → 顶层黑金（bar 背景与描边同步加深）。
