# 00 · 游戏总览

## 1. 定位

- **题材**：都市女性向上社交——不靠暧昧、靠擦边、靠身体，更加靠关系经营。
- **品类**：放置（Idle）+ 轻模拟经营。
- **平台**：steam 电脑平台，windows 版本。和tbh一样，只做一个bar
- **目标用户**： 办公室男女，工作摸鱼解压的时候操作，大多数时间全天挂机。

## 2. 核心循环

```
遇见NPC → 花时间/资源攻略 → 好感达标
   ↑                            ↓
解锁更高圈层 ← NPC成为人脉资产，持续产出资源
```

一句话：**关系即资产**。NPC 是本作唯一的"生产建筑"：

| 放置游戏概念 | 本作包装 |
| --- | --- |
| 建筑解锁 | 结识 NPC |
| 建造中 | 攻略中（好感度增长） |
| 建成投产 | 好感满级 → 人脉资产 |
| 扩产 | 圈层提升 + 个人属性成长 |
| 解锁新地图 | 进入更高圈层 |

## 3. 三条设计支柱

1. **每次上线都有收获**——离线期间好感与资源持续累积，回归必有待领节点。
2. **关系即资产**——所有投入都转化为可持续产出的"人脉资产"，不做随机失败、不惩罚玩家。
3. **向上不是恋爱是经营**——情感是调味，资源与地位成长是主线；文案清醒、体面、搞钱向。

## 4. MVP 系统范围

只做 4 个一级系统。`start.md` 完整愿景的其余部分全部后置。

| 系统 | MVP 做法 | start.md 对应 | 后置到二期 |
| --- | --- | --- | --- |
| NPC 系统 | 5 圈层 × 6 人 = 30 个 NPC，3 种类型 | NPC系统 / 人脉系统 | 随机场合刷新、更多圈层 |
| 好感度系统 | 单维好感 0~100，槽位制 | 社交博弈 / 识人 | 信任/价值感三维、博弈事件 |
| 资源经济 | 金币 / 体力 / 声望 三资源 | 业务量 → 收入 | 行业人脉、业务系统（循环 B） |
| 个人属性 | 魅力 / 谈吐 / 品味 三项 | 成长系统 | 技能、宝物、宠物 |
| —— | 无职业系统 | 打工10级/创业10级 | 用"身份等级"承接（见 04-roadmap） |
| —— | 无自动化管家 | 自动化系统 | 智能管家作为后期养成终点 |

## 5. 玩家体验节奏目标（验收红线）

| 时间点 | 玩家应该体验到 |
| --- | --- |
| 首次上线 10 分钟内 | 攻略完第一个 NPC，看到"资产开始产钱" |
| 第 1 天结束 | 通第一圈层（职场圈），摸到第二圈层门票 |
| 每次睡醒回来 | 有 2~3 个里程碑节点可领 |
| 每次上线 3 分钟 | 至少做出 1 个决策：换槽位 / 送礼 / 升属性 |
| 全生命周期 | 约 6~8 周通到顶层圈（MVP 版内容边界） |

## 6. 明确砍掉的东西（防蔓延）

- 随机创业失败、抽卡式结识、体力买断付费墙、PVP、公会。
- 三行业（金融/地产/高科技）在 MVP 中不存在，圈层即行业抽象。

## 7. 术语表

| 术语 | 含义 |
| --- | --- |
| 圈层 | NPC 所处社会阶层，共 5 层，进入需声望门槛+入场费 |
| 攻略槽位 | 同时主动培养关系的名额，初始 3 个 |
| 人脉资产 | 好感满级的 NPC，转为持续产出单位 |
| 引荐 | 特定 NPC 满级后提前解锁上一圈层的指定 NPC |
| 矜持系数 | 高圈层 NPC 好感增长变慢的修正系数 |
