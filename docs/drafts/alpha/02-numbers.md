- 矜持系数除在自动好感速率上：高圈层不是不能攻略，是更慢、更贵。

## 2. 核心公式

```text
资产产出(金/秒) = 个体基础产出 × 圈层倍率 × 个体系数(0.8~1.5)

自动好感(好/分) = 0.5 × (1 + 0.08×魅力等级) ÷ 矜持系数
                  × (1 + 辅助型加成)

互动好感(每次)  = 自动好感 × 5分钟 × (1 + 0.08×谈吐等级)
                 （消耗 10 体力）

属性升级成本    = 150 × 1.7^当前等级 （金）
```

## 8. 体力与离线

| 项 | 数值 |
| --- | --- |
| 体力上限 | 100 |
| 回复速度 | 1 点 / 3 分钟（= 20/小时） |
| 单次互动消耗 | 10 |
| 离线结算上限 | 12 小时（辅助加成最高 +12h） |
| 离线好感效率 | 自动速率 ×50% |

设计意图：体力存量支撑约 5~8 次互动 ≈ 单次上线 3~5 分钟的操作预算。

## 9. 节奏验算示例（首日）

```text
0~10 分钟   教学：攻略林晓芸(声望型)至满 → 首个资产上线(约1金/秒)
10~60 分钟  攻顾言(金钱型)，何丽娜入槽；里程碑金币滚动
睡前        3 槽满员离线，8 小时 ≈ 4 好/分 ×50% ×8h ≈ 每人 +96 好感进度
次日早上    领 2~3 个节点 → 林晓芸已满级 → 声望累计过百 → 进精英圈
```

> 以上为手算示意，以 Excel 表为准。
