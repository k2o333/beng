# 01 · 模块 A：体力与管理后台

> 需求：① 恢复速度暂定 **20 点/分钟**；② 提供管理后台，恢复速度可配置。

## 1. 体力新基准

| 项 | v1 | v2 提案 | 说明 |
| --- | --- | --- | --- |
| 恢复速度 | 1 点/3 分钟（20/小时） | **20 点/分钟**（1200/小时） | 需求指定；为自动攻略的持续供给兜底 |
| 上限 | 100 | 100（可配置） | 20/分钟 ≈ 5 分钟回满，上限不再是瓶颈 |
| 互动消耗 | 10 | 10（可配置） | 体力满时 ≈ 2 次互动/分钟 |
| 离线回复 | 照常 | 照常（可关） | 管理后台可配置 |
| 体力定位 | 手动操作预算 | **主角 Agent 的行动燃料**（自动攻略耗体力）+ 手动加速 | 与 04 模块强耦合 |

设计意图：体力从"限制玩家操作"转为"**限制主角自动社交的强度**"——
恢复速度就是游戏难度的总旋钮，所以必须进后台可配置。

## 2. 管理后台

### 2.0 形态决策（已拍板）

**方案 A：设置面板内嵌"管理后台"页**——游戏设置里加一页，参数表单 + 预设 + GM 按钮，改动即时生效并写入存档。
（被否的方案 B 是"快捷键呼出独立悬浮调试窗+实时曲线"，仅封测期调参有用，后置可选。）

### 2.1 定位

单机 Steam 游戏的**"导演模式"**：玩家自调难度与节奏；开发期兼作数值调参台。
不联网、无作弊检测；改动后存档打上 `customMode` 标记（二期成就系统据此判定公平性）。

### 2.2 可配置项全目录（v2）

**体力组**

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| staminaRegenPerMin | 20 | 0~999 | 体力恢复/分钟（**需求核心项**） |
| staminaMax | 100 | 10~999 | 体力上限 |
| interactStaminaCost | 10 | 0~100 | 线下互动消耗 |
| wechatStaminaCost | 2 | 0~50 | 微信聊天消耗 |
| workplaceInteractCost | 6 | 0~50 | 职场互动消耗 |
| offlineRegen | 开 | 开/关 | 离线是否回复体力 |

**时间组**

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| timeScale | 1.0 | 0.5~5.0 | 游戏时间流速（影响恢复/掉落/冷却/离线判定） |
| offlineCapHours | 12 | 1~168 | 离线结算上限 |
| offlineFavorRate | 50% | 0~200% | 离线好感效率 |

**经济组**

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |

| dropValueRate | 100% | 10~1000% | 掉落期望价值倍率 |
| itemDropChance | 按 07 基准 | 0~100% | 物品掉落占比 |
| rareItemRate | 按 07 基准 | 0~100% | 稀有品质权重 |

| favorPerYuanRate | 100% | 10~1000% | 消费项目好感倍率 |
| workWageRate | 100% | 10~1000% | 工作时薪倍率 |
| tipChance | 按 02 基准 | 0~100% | 奶茶店小费概率 |

**GM 工具（一次性）**

| 功能 | 说明 |

| 全 NPC 好感 +10 | 调试用 |
| 重置存档 / 导出 / 导入 | 存档管理 |

**界面组**

| --- | ---: | --- |

| decisionLogDepth | 50 | 决策日志保留条数 |

### 2.3 预设

| 预设 | 关键项 | 目标人群 |
| --- | --- | --- |
| 标准 | 全默认 | 基准体验 |
| 休闲 | 体力 40/分钟、物价 80%、掉落期望 120% | 只想看小人挂机 |
| 极速 | 体力 60/分钟、timeScale 2.0、预算不限 | 速通/数值验证 |
| 自定义 | 手改任意项后自动落入 | 全体 |
