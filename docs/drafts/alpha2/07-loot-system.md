# 07 · 掉落与物品系统（资产产出的随机化重构）

> 需求修订（拍板）：资产产出**不再按秒给钱**，改为——
> **每过一段随机时间，随机给一笔钱或一件物品，物品带各种效果。**
> 本文档定义掉落规则、物品表、拾取与离线折算；03 档案的"产出"字段自本档起按掉落口径解读。

## 1. 掉落规则

### 1.1 触发

- 只有**人脉资产**（满级 NPC）掉落；槽内攻略期不掉（攻略期的产出是好感进度本身）；
- 每个资产独立计时：`间隔 = 层基准 × 系数修正 × dropIntervalRate × random(0.7~1.3)`；

| 层 | 基准间隔 | 系数修正 | 约掉落频率 |
| --- | ---: | ---: | ---: |
| T1 | 120 秒 | ÷ 个体系数 | 30 次/时 |
| T2 | 150 秒 | 同上 | 24 次/时 |
| T3 | 240 秒 | 同上 | 15 次/时 |
| T4 | 420 秒 | 同上 | 8.5 次/时 |
| T5 | 720 秒 | 同上 | 5 次/时 |

### 1.2 期望价值校准（与 v1 秒产对齐）

```text
金币包期望：E[金/时] = v1口径金/秒 × 3600 × dropValueRate
  例：顾言（v1 1.2 金/秒）→ 期望 4320 金/时 → 每包 ≈ 144 金 × random(0.6~1.4)
```

- 单次到账有波动，**长期期望不变**——总经济盘子与 06 校准表一致；
- 声望型资产：掉**声望手札**（固定值 T1~T5 = 1/2/4/8/15 声望），间隔 ×2（v1 被动声望的随机化替代，期望略上调，见 06 待校准）。

### 1.3 掉落内容表（按 NPC 类型分流）

| 类型 | 主要掉落 | 次要 | 稀有 |
| --- | --- | --- | --- |
| 金钱型 | 金币包 70% | 礼物盒/限量藏品 20% | 功能物品 10% |
| 声望型 | 声望手札 55% | 情报类 20% | 金币包 15% / 功能 10% |
| 辅助型 | 功能物品 45% | 金币包 35% | 稀有物品权重 ×2 |

**品质**：普通 80% / 精致 17% / 稀有 3%（`rareItemRate` 可调；精致=效果 ×1.5，稀有=唯一效果）。

## 2. 物品表（v2 首批 12 件）

| 物品 | 品质 | 效果 |
| --- | --- | --- |
| 心动奶茶券 | 普通 | 随机一名槽内 NPC +3 好感 |
| 体力咖啡 | 普通 | 体力 +30 |
| 纪念品 | 普通 | 可送任意 NPC，+2 好感 |
| 商务名片夹 | 普通 | 24h 内约会价格 8 折 |
| 内部简报 | 普通 | 声望 +2（按层放大：×层倍率/10 取整） |
| 手写请柬 | 精致 | 指定 NPC 免费轻约一次 |
| 双人展票 | 精致 | 触发一次免费约会（自动匹配偏好变体，走事件表，见 08） |
| 品味画册 | 精致 | 下一次属性升级 5 折 |
| 惊喜蛋糕 | 精致 | 全部槽内 NPC +2 好感 |
| 礼物盒 | 精致 | 当作"中礼"送出（免费，可攒） |
| 引荐名片 | 稀有 | 解锁一名未结识的上一层 NPC（引荐位之外的额外位） |
| 限量藏品（球鞋/绝版书/黑胶） | 稀有 | 等效"大礼"的礼物，送出带专属文案 |

- 物品用途：使用 / 送出 / 出售（折价 30% 入金币）；背包上限 50，满了优先挤掉普通品质；
- 决策器会用物品：缺体力吃咖啡、收网期掏礼物盒/限量藏品（不花预算，优先级高于购买）。

## 3. 拾取与表现（TBH 式桌面反馈）

- 掉落在 bar 舞台该 NPC 头顶冒出图标（金币袋/礼包/物品），落地弹跳两次；
- `autoPickup` 开（默认）：3 秒后自动入包；
- 关掉时手动点击拾取，**3 秒内点中 = 概率暴击 ×2**（主动摸鱼的甜头）；
- 离线期间掉落按期望值折算成**离线包裹**，回归简报里一次性开包（保留开箱爽感）。

## 4. 与其他模块的接口

- 01 管理后台：`dropIntervalRate`、`dropValueRate`、`itemDropChance`、`rareItemRate`、`autoPickup`；
- 04 决策器：物品是免费动作来源（优先级高于花钱）；
- 08 约会随机：约会事件的掉落走同一物品表；
- 03 档案卡：【产出】行改为"掉落口径"（例：顾言——每 2 分钟左右掉一次金币包，期望 4320/时，偶尔回赠礼物）。
