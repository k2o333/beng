# 05 · 模块 E：明确的花钱选项（消费项目系统）

> 需求：角色攻略 NPC 应该有**明确的花钱选项**（参照已有游戏的送礼/约会分层 + 放置游戏的确定性价目表）。

## 1. 设计原则

1. **价目表永远透明**：每个项目标价、好感收益、解锁条件一目了然，玩家能心算性价比；
2. **花钱买速度，不买运气**：沿袭"不随机失败"——贵的项目单位好感更贵，但**即时、大额**；
3. **自动与手动同价同表**：主角决策器（04）和玩家手动点按走同一张价目表、同一份预算护栏；
4. **偏好匹配给决策空间**：选对项目比堆钱更有效，"知道他喜欢什么"成为攻略价值的一部分。

## 2. 消费项目总表

### 2.1 送礼（沿用 v1 表，基准）

| 档位 | 好感 | 价格公式 | T1 示例 | 解锁 |
| --- | --: | --- | ---: | --- |
| 小礼 | +4 | 80×5^(层-1) | 80 | 无 |
| 中礼 | +10 | 250×5^(层-1) | 250 | 无 |
| 大礼 | +25 | 800×5^(层-1) | 800 | 品味 ≥ ⌈层门槛/2⌉ |

### 2.2 约会（v2 新增，三档 × 场景变体）

| 档位 | 好感 | 价格公式 | T1 示例 | 解锁 |
| --- | --: | --- | ---: | --- |
| 轻约 | +6 | 小礼 ×1.5 | 120 | 无 |
| 正餐 | +15 | 中礼 ×1.5 | 375 | 好感 ≥25 |
| 远行 | +35 | 大礼 ×2.5 | 2000 | 好感 ≥50 |

**场景变体**（同档同价，tag 不同）：

| 档位 | 变体 | 场景 tag |
| --- | --- | --- |
| 轻约 | 街角咖啡 / 看展 / 球赛 | 市井+美食 / 文艺+收藏 / 运动+时尚 |
| 正餐 | 家常馆子 / 商务宴请 / 私厨 | 市井+美食 / 商务+酒局 / 美食+收藏 |
| 远行 | 音乐节之旅 / 城市漫游 / 高尔夫周末 | 文艺+时尚 / 美食+旅行 / 商务+运动 |

### 2.3 办事帮忙（v2 新增，大额一次性）

| 项目 | 好感 | 价格公式 | T1 示例 | 解锁 |
| --- | --: | --- | ---: | --- |
| 办事（帮他把一件事办成） | +60 | 大礼 ×6 | 4800 | 好感 ≥75，**每人限一次** |

定位：里程碑跳板——卡在 95~100 或冲满级仪式感时的大招；单位好感最贵，但一次 +60。

### 2.4 效率梯度（好感/元，T1 口径）

```text
小礼 0.050 ≈ 轻约 0.050 ≈ 正餐 0.040 ≈ 中礼 0.040 > 大礼 0.031 > 远行 0.018 > 办事 0.013
```

便宜项目效率高（适合挂机慢磨），大额项目即时跳跃（适合推节点/收尾）——
**手动玩家与决策器共享这条效率曲线**，钱永远花得明白。

## 3. 偏好匹配

- 每个 NPC 两个**偏好 tag**（见 03 档案卡：商务/科技/文艺/时尚/美食/酒局/运动/旅行/收藏/学术/公益/市井）；
- 每个约会变体带两个场景 tag；**交集 ≥1 → 好感 ×1.2，无交集 → ×0.8**；
- 送礼/办事不受偏好影响（通用项目）；
- UI：消费菜单里匹配项亮"投其所好"角标；决策器永远优先选匹配变体；
- 示例：顾言偏好（科技、市井）——轻约选"街角咖啡"（市井+美食）命中市井 → +6×1.2=7.2 好感；选"看展"（文艺+收藏）无交集 → +6×0.8=4.8 好感。

## 4. 花钱入口

| 入口 | 行为 |
| --- | --- |
| 攻略面板·NPC 卡"消费"展开 | 六档项目全列出：标价/好感/解锁条件/匹配角标，点按立即执行 |
| 决策器 | 按 04 的评分制在预算内自动选购（同表同价） |
| 管理后台 | `priceRate`、`giftFavorRate` 全局调节（01） |

预算护栏（与 04 共用）：全局日预算 + 单人日预算，**超线只做免费动作**——免费动作池的完整定义见 `04-idle-courting.md` §2.3（互动/微信/朋友圈/物品使用/邀约，花好感不花钱）。

## 5. 渠道与随机（v2 修订）

- **渠道约束**（02 §4）：送礼/约会/办事属线下动作，仅主角**下班时段**可执行；在岗期决策器只动嘴（微信/职场互动）；
- **随机机制**（08）：约会结算叠加事件表（惊喜掉物品/偶遇贵人）、NPC 回礼、主动邀约、热点日历加成；
  礼物本身也有免费来源（掉落的礼物盒/限量藏品、回礼）——花钱不是唯一获取路径，但永远是最快路径。

## 6. 参照与差异

| 参照 | 借鉴 | v2 的差异 |
| --- | --- | --- |
| 恋与制作人/如鸢类送礼分层 | 档位化礼物、角色偏好加成 | 无卡池无抽卡，纯明码标价 |
| 放置游戏升级菜单 | 确定性价目、效率可心算 | 消费对象是"人"，有解锁条件与叙事 |
| TBH 的开箱反馈 | 花钱即得确定反馈 | 无随机品质，反馈=好感数字+文案 |
