# 08 · 约会随机机制（回应"除了智能购买，还有什么随机获得"）

> 需求：约会/送礼除了主角智能选购外，还要有随机获得类机制。
> 原则不变：**随机只带来惊喜或平局，不带来惩罚**（最差结果是"效率打折"，永不亏本）。

## 1. 机制总览（五件套）

```text
约会事件表 ── 每次约会掷一次：平淡/相谈甚欢/小插曲/惊喜/偶遇贵人
NPC 回礼   ── 送大礼/办事后，他有概率回赠你东西
主动邀约   ── 好感够高的 NPC 会反过来约你（免费约会）
热点日历   ── 城市每天刷新热点，约对日子事半功倍
情报物品   ── 揭示 NPC 隐藏偏好/引荐线索，提升后续所有决策质量
```

## 2. 约会事件表

每次约会/送礼在基础好感之上掷一次事件：

| 事件 | 权重 | 效果 | 表现 |
| --- | ---: | --- | --- |
| 顺其自然 | 60% | 标准好感 | 正常文案 |
| 相谈甚欢 | 20% | 好感 ×1.5 | 头顶"相谈甚欢!" |
| 小插曲 | 12% | 好感 ×0.7（仍正收益） | 趣味文案（上错菜/下雨没伞） |
| 惊喜时刻 | 5% | 好感 ×2 + **掉落一件纪念品**（07 物品表） | 金光 + 专属文案 |
| 偶遇贵人 | 3% | 标准好感 + **情报/引荐线索物品** | 第三方入镜的演出 |

**权重修正**：
- 偏好匹配命中 → "惊喜时刻"权重 ×2；
- 热点日历命中 → "相谈甚欢"与"惊喜时刻"权重 ×2；
- 消费风格豪掷 → 全部正向事件权重 +20%（钱多，运气也好一点，仅此而已）。

## 3. NPC 回礼

- 触发：大礼 / 远行 / 办事结算后，8% 概率；
- 内容：从 07 物品表随机，**品质 +1 档**（普通→精致→稀有）；
- 防刷：每 NPC 每游戏周最多 1 次；
- 叙事：回礼带专属文案（他送你一支他惯用的钢笔/两张他策展的票）——关系变成双向的。

## 4. NPC 主动邀约（反向攻略）

- 条件：好感 ≥40；每游戏日判定一次：`P = 15% × 匹配系数(0.8/1.2)`；
- 形式：NPC 发来邀约（舞台气泡 + 简报），24 游戏小时内有效；
- 接受（默认自动接受，可在设置改"询问我"）= **免费的正餐档约会**（走事件表，可出惊喜/贵人）；
- 忽略 = 过期消失，**无任何惩罚**；
- 价值：省钱的意外之喜 + "他也开始主动了"的关系进展叙事。

## 5. 热点日历（城市节奏）

- 每游戏日早 8 点刷新 1~2 个热点：画廊新展（文艺/收藏）、联赛决赛（运动/时尚）、
  新品首发（科技/时尚）、米其林新榜（美食/商务）、慈善拍卖（收藏/公益）……
- 当日用命中热点的变体约会：好感效率 +20%，且正向事件权重翻倍（§2）；
- 决策器会**为热点改计划**（"今天有拍卖夜宴，把叶铮的正餐改到今天"）——
  玩家在简报里看到这种调度，就是"主角真的在替你经营关系"的实感；
- UI：bar 角标轮播"今日热点"，点开看 tag 与剩余时间。

## 6. 情报物品（识人玩法的种子）

- 来源：声望型资产掉落（07）、约会"偶遇贵人"事件；
- 使用后三选一随机揭示一名已结识 NPC 的隐藏信息：
  1. **第三偏好**——匹配判定窗口从 2 tag 扩到 3 tag（命中率↑）；
  2. **引荐线索**——提示"谁能引荐他"（即使没有引荐位的 NPC 也给社交路径提示）；
  3. **雷区**——一个错配 tag（决策器自动避开该变体）；
- 定位：花掉情报 = 提升之后每一次消费的期望价值，呼应 start.md 识人系统。

## 7. 礼物的"随机获得"渠道汇总（回答需求原文）

| 渠道 | 机制 | 出处 |
| --- | --- | --- |
| 资产掉落 | 礼物盒（等效中礼）/限量藏品（等效大礼）免费送 | 07 |
| 约会惊喜 | 惊喜时刻掉纪念品/物品 | 08 §2 |
| NPC 回礼 | 品质+1 的回赠 | 08 §3 |
| 主动邀约 | 免费正餐档约会 | 08 §4 |
| 热点日历 | 不给实物，给 +20% 与事件权重 | 08 §5 |
| 情报物品 | 间接：提升匹配率=提升每分钱效率 | 08 §6 |
