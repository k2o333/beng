# 00 · Alpha2 总览

## 1. 这轮优化的本质

v1 的玩家是"操作员"：手动互动、手动送礼、手动换槽。
v2 把主角变成 **Agent（自动经营的"我"）**，玩家退到**战略层**：

| 层 | v1 | v2 |
| --- | --- | --- |
| 战略层（玩家） | 混在操作里 | **攻略谁、花多少钱、消费风格、排不排班** |
| 战术层（主角 AI） | 无 | 自动选动作、自动花钱、自动换槽、离线照跑 |
| 运营层（后台） | 无 | 体力/经济参数可配置（管理后台） |

这正是 `../start.md` §16"操作期/放置期统一"与 §17"智能管家"的**第一步落地**：
管家还不会"识人止损"，但已经会"按预算把人攻略到手"。

## 2. 核心循环的增量

```text
            ┌─ 新增：基础工作（现金流兜底，循环 B 的种子）
启动资金 10000 ┤
            └─→ 认识 NPC → 【自动攻略（花时间+花钱）】→ 好感达标
                  ↑                              ↓
              管理后台调参            人脉资产持续产钱 → 攻略更高圈层
```

循环 A（关系）结构不变；循环 B（职业）以"基础工作"形式埋下第一块砖。

## 3. 五点需求的系统影响面

| 需求 | 新增系统 | 改动的既有系统 | 不动的部分 |
| --- | --- | --- | --- |
| 体力+后台 | 管理后台 | 体力结算、离线结算 | 互动/好感公式 |
| 工作+启动金 | 工作排班 | 开局状态、经济闭环前段 | 资产产出、圈层门槛 |
| 全男性 NPC | — | 30 人内容包、外观表 | 类型配比、系数、引荐结构 |
| 全自动攻略 | 决策器（主角 AI） | 槽位操作方式、离线结算、简报 | 好感数值、里程碑、满级转化 |
| 花钱选项 | 消费项目+偏好 | 送礼系统扩容 | 礼物价位基准（×5/层） |

## 4. 体验目标（验收红线草案）

| 时间点 | 玩家应体验到 |
| --- | --- |
| 开局 | 10000 元到账 + 入职一份工作 + 第一目标自动进槽开攻 |
| 开局 10 分钟 | **不碰任何按钮**的情况下看到首个资产上线（全自动跑通） |
| 每次回归 | 离线简报讲清"主角昨晚替你花了哪些钱、办成了什么" |
| 3 分钟上线 | 做的全是战略决策：换目标、改预算、调消费风格、排班 |
| 全生命周期 | 6~8 周通关（与 v1 持平，自动化不缩短总周期，只降低操作密度） |

## 5. 明确不做（仍属 start.md 二期+）

- 行业选择（金融/地产/高科技）、打工 10 级/创业 10 级、业务量与升职——基础工作只是其 Lv0 前置；
- 信任/价值感三维关系、识人博弈、随机事件；
- 智能管家的"止损替换/战略目标推导"（v2 只做"按预算执行+顺序补位"）。

## 6. 决策点清单（需要拍板）

1. 01：管理后台做内嵌页（A）还是独立调试窗（B）？
2. 02：工作用排班制（A，与体力联动）还是被动挂机制（B）？
3. 03：13 名女性 NPC 的替换名册是否认可？
4. 04：决策器用评分制（推荐）还是简单阈值？手动操作是否保留为可选加速？
5. 05：约会/办事项目的价格带与偏好加成幅度是否认可？
