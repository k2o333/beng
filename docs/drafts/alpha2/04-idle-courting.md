# 04 · 模块 D：全自动攻略（主角 Agent）

> 需求：攻略过程应该是**放置的，不需要人操作的**。角色自动决定什么时候、花什么钱。
> v2 修订：弃用单一评分器（局限：只看眼前一步、行为没人味、不会分阶段），改为**分层决策架构（方案 C）**。
> 对应 `../start.md` §16 放置期、§17 智能管家的第一步。

## 1. 设计原则

1. **玩家做战略，主角做战术**：玩家定攻略谁/预算/风格/体力分配；主角定何时聊、送什么、何时约会、满级换谁。
2. **行为要像"人"**：刚认识就送大礼很失礼——决策器必须懂"关系阶段"，不同阶段干不同的事。
3. **可解释**：每个花钱动作进决策日志，简报能讲清"昨晚主角替你做了什么、为什么"。
4. **不惩罚**：只做非负收益的事；预算护栏是硬约束。
5. **可关**：手动保留为可选加速，全程不碰按钮也能通关（验收红线）。

## 2. 分层决策架构（方案 C）

```text
L0 战略层（玩家配置）      攻略队列 / 消费风格 / 预算 / 体力分配 / 渠道优先级
        ↓
L1 阶段剧本层（关系阶段）  每段关系处于哪个阶段 → 该阶段的动作白名单 + 节奏约束 + 阶段目标
        ↓
L2 执行层（效用评分）      白名单内选性价比最高的具体动作（评分器在这里，只是执行件）
        ↓
L3 中断层（事件驱动）      体力满 / 里程碑可领 / NPC 邀约 / 掉落可拾取 → 插队处理
```

### 2.1 L0 战略层（玩家唯一需要碰的地方）

| 配置 | 选项 |
| --- | --- |
| 攻略队列 | 手动拖拽排序（默认）/ 自动排序（产出/声望/引荐优先） |
| 消费风格 | 节俭 / 标准（默认）/ 大方 / 豪掷 |
| 预算 | 全局日预算 20000（0=不限）/ 单人日预算 5000 |
| 体力分配 | 先工作后社交 / 先社交后工作 / 比例分配 |
| 大额支出 | 槽位费、圈层入场费**永远不自动花**（底线） |

### 2.2 L1 阶段剧本层（本方案的灵魂）

每段关系按好感走五个阶段，**每阶段一份剧本**（动作白名单 + 节奏约束 + 目标）：

| 阶段 | 好感 | 白名单 | 节奏约束（防失礼/防浪费） | 阶段目标 |
| --- | --- | --- | --- | --- |
| 破冰 | 0~24 | 微信、职场互动、互动 | **禁一切消费**——不熟就送礼会被挡回来 | 好感 25，解锁正餐 |
| 升温 | 25~49 | +轻约、小礼、中礼 | 单日消费 ≤ 单人预算 50% | 好感 50，解锁远行 |
| 深交 | 50~74 | +远行、大礼 | 偏好匹配优先（05） | 好感 75 |
| 收网 | 75~99 | +办事 | 里程碑差 ≤3 好感时全力推 | 满级转化 |
| 维稳 | 资产 | 无（转产出） | — | 槽位让贤 |

- 阶段剧本就是**内容载体**：每个阶段切换配一句主角内心独白（"该请他吃个饭了"）；
- 消费风格调制白名单：豪掷 = 解锁全部（跳阶段约束但多花钱）；节俭 = 只保留免费+小礼；
- 好处：行为可读、天然防呆（不会在破冰期烧预算）、文案有挂点。

### 2.3 L2 执行层（效用评分，只做选择题）

在白名单内对每个可用动作打分，取最高：

```text
score = Δ好感 × 匹配系数 × 事件加成 ÷ (α × 金币成本/当前财力 + β × 体力成本)
  匹配系数：偏好命中 ×1.2 / 错配 ×0.8（05）
  事件加成：热点日历命中 ×1.2、NPC 邀约免费 ×2（08）
  α=0.02、β=1.0（管理后台可调）
```

约束检查在打分前：预算超线/体力不足/冷却中 → 直接出局。

### 2.4 免费动作池（预算超线时的行为兜底）

**免费的定义：不花金币、不占预算**——但可以耗体力、耗物品、受冷却限制。
预算超线（全局或单人任一达线）时，决策器整体切换到免费池，主角"只动嘴不动钱"：

| 免费动作 | 好感 | 消耗 | 冷却 | 渠道/时段 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 线下互动 | 2.5×加成 | 10 体力 | 无 | 下班 | 主力免费进度 |
| 职场互动 | +3 | 6 体力 | 60 分/NPC | 在岗，仅 T1 | 同事当面处 |
| 微信聊天 | +2（固定） | 2 体力 | 30 分/NPC | 任意时段 | 效率低但全天可用 |
| 朋友圈互动 | +1 | 0 体力 | 2 时/NPC | 任意时段 | 点赞/评论，零成本保底 |
| 使用物品 | 按物品 | 物品 | — | 按物品 | **不受预算限制**（见下） |
| 接受邀约 | 正餐档 | 免费 | 事件驱动 | 事件 | 08 §4 |

规则：

1. **优先级**（体力效率降序）：职场互动 > 线下互动 > 微信 > 朋友圈；同 NPC 冷却中自动换下一个目标/动作；
2. **物品豁免**：背包物品（礼物盒/奶茶券/蛋糕等）不算预算——它们是奖励不是现金；
   决策器在超线期会优先掏物品（"钱花完了，但抽屉里还有他送的茶"）；
3. **免费池也有节奏**：全部冷却中 + 体力见底 = 主角合法休息（放置游戏允许"没事发生"）；
4. **阶段剧本兼容**：破冰期（禁消费）本来就只跑免费池——免费池同时是"穷玩法"和"礼貌玩法"。

### 2.5 L3 中断层

| 事件 | 响应 |
| --- | --- |
| 体力回满溢出 | 立即消耗（优先高效率动作） |
| 里程碑差 ≤3 好感 | 提权：score ×1.5，优先领奖点 |
| NPC 主动邀约（08） | 按策略自动接受（默认接受，免费高效） |
| 掉落物落地（07） | 自动拾取（或提示手动点击暴击） |

决策周期默认 5 秒（`decisionIntervalSec`）。

## 3. 自动换槽

```text
满级 → 转资产 → 槽位空出 → 候补队列顶上补位 → 新关系进入破冰期
```

- 队列排序：手动拖拽（默认）/ 自动（产出/声望/引荐优先）；
- 槽位扩容费、圈层入场费不自动花。

## 4. 渠道感知（与 02 联动）

| 时段 | 决策器可用动作 |
| --- | --- |
| 在岗 | 微信聊天 + 职场互动（仅 T1 在槽） |
| 下班 | 全动作；在岗顺延的约会自动补上 |
| 体力不足 | 按"职场互动 > 微信 > 线下"自然降级 |

## 5. 离线与简报

- 离线按同一架构模拟（阶段剧本 + 预算 + 渠道按排班折算），好感受离线效率 50% 约束；
- 简报"主角动态"示例：

```text
昨晚主角：
· 白班 8h：时薪 +240；职场互动顾言 ×3（+9）；微信维持何丽娜 ×2
· 下班后：请陆之衍商务宴（命中偏好，+18）；送祁墨小礼（+4）
· 里程碑：顾言 50 好感达成，+750 金
· 预算：今日已花 4,860 / 20,000
```

## 6. UI 呈现

- NPC 头顶状态角标：阶段图标（破冰/升温/深交/收网）+ 暂停原因（预算/体力/冷却）；
- 攻略面板：卡片显示当前阶段 + 最近动作 + 原因；决策日志最近 50 条（`decisionLogDepth` 可调）；
- 阶段切换时主角独白 toast（可关）。

## 7. 手动操作的去留

手动 = "立即执行"按钮：走同一白名单（可越阶段，多花 20% 价格作为"失礼成本"？——**否**，v2 不做惩罚，手动只是跳过排队直接执行，同价同表）。

## 8. 为什么比单一评分器好（回应局限性质疑）

| 单一评分器的局限 | 方案 C 的解法 |
| --- | --- |
| 只看眼前一步，不会"攒钱办大事" | 阶段目标 + 预算分日规划，收网期自然蓄力 |
| 行为没人味（机器人式撒钱） | 阶段剧本：破冰不花钱，深交才远行——像真人社交节奏 |
| 权重难调、牵一发动全身 | 分层后每层职责单一：剧本管"能不能"，评分只管"选哪个" |
| 无法表达"策略" | 消费风格 + 队列 + 预算 = 玩家的可配置策略；二期智能管家直接替换 L0 |
