# 下一轮迭代草案：合成 / 成就层 / Bar 形态改造

> 高优先借鉴项（源自 TBH 调研，`../research/tbh-reference.md`）+ 本次讨论新增的 Bar 形态需求 + 背包/掉落答疑。
> 状态：草案，待拍板后排期。

## 1. 物品合成：3 合 1 升品质（TBH 9 合 1 的轻量版）

**问题**：普通品质掉落泛滥（见 §4 测算），无消耗出口；稀有物品又太稀有。

**方案**：
- 背包页新增「合成」操作：选中 3 件**同品质**物品 → 合成 1 件**高一档品质**的随机物品（普通→精致→稀有，稀有不可再合）；
- 决策器不自动合成（留给玩家当 3 分钟决策之一）；管理后台可加 GM 合成按钮调试验证；
- 合成结果从全物品表均匀随机（含 send 类，合成出礼物盒=变相攒礼）。

**验收**：3 普通 → 必得 1 精致；数量不足 3 件时按钮禁用；合成动画期间防重复点击。

**成本**：约 60 行（`Engine.synthItems` + 背包页多选与按钮）。

## 2. 账号级被动成就层（TBH 宠物系统的同构）

**问题**：辅助型资产之外缺少账号级长线成长；放置游戏的留存钩子是"永远差一点的全局加成"。

**方案**（成就即被动，永久生效，文案走打工人共鸣风）：

| 成就 | 达成条件 | 永久被动 |
| --- | --- | --- |
| 摸鱼大师 | 累计线下互动 1000 次 | 全局好感 +3% |
| 全勤打工人 | 累计上班 100 游戏小时 | 时薪 +10% |
| 捡漏之王 | 累计拾取掉落 500 件 | 掉落间隔 -5% |
| 社交悍匪 | 累计约会 100 次 | 约会价格 -5% |
| 人脉广博 | 资产数达到 10 | 体力上限 +20 |

- 计数器挂 `state.stats`（部分已有），达成即写入 `state.perks`，结算处读取；
- 展示位：属性页底部新增「成就」分组（已达成亮起 + 被动生效中）；
- 文案基调对齐 TBH 的 "Hell? Better Than Monday"：自嘲、清醒、面向上。

**验收**：达成瞬间 toast + 属性页亮起；被动数值进对应结算管线（好感/工资/掉落/约会价/体力上限）；存档迁移兼容（旧档 stats 缺字段按 0 计）。

**成本**：约 1 天（成就表 + 5 处结算管线接入 + UI）。

## 3. Bar 形态改造：默认 1/5 宽、可调、可挪动、详情直达

**参照**：TBH 的 bar 可拖到屏幕任意位置、可缩到约 1/5 屏宽，展开后可见背包/人物详情。

**核心决定：默认形态就是 1/5 屏宽的迷你条，宽度由用户在 1/5 ↔ 全宽之间任意调整**（v2 现状的"贴底全宽"只是调节范围的一端，不再是默认）。

### 3.1 宽度调节（1/5 ↔ 全宽）

- **档位预设**：1/5（默认）/ 1/3 / 1/2 / 全宽，右键菜单 + 设置页各一处；
- **自由拖拽**：bar 左右边缘有拖拽热区，任意宽度连续可调（松手吸附到最近档位亦可，取"连续可调+边缘热区"方案，预设档位作为双击边缘的快捷切换）；
- 宽度持久化到 main 进程 `cfg.json`（与 pixelScale 同级），重启保持；
- **HUD 响应式分档**：
  - ≤1/3 宽：金币/声望/收入收进图标+数字（无标签），体力条保留；
  - 1/5 宽：HUD 压缩为两行微型（💰/⚡ 数字 + 迷你体力条），功能页签收进「☰」菜单按钮；
- **舞台分档**：1/5 宽（~380px）下同屏 2~3 个 NPC（12px×3 像素小人约 150px），槽位超出部分左右滚动或轮播（优先滚动，滚轮/边缘箭头）；
- 掉落物、主角小人、阶段角标在窄条下全部保留，字号随档位微降。

### 3.2 自由挪动

- bar 脱离"贴底全宽"约束，可拖拽吸附四边（上/下/左/右）或悬浮任意位置；
- main.js 的 `setBounds` 改造为按 anchor + 宽高计算；托盘菜单加「重置位置」；
- 面板展开方向随吸附边自适应（贴顶向下展开，贴底向上展开）。

### 3.3 详情直达 + 网格化 + 分类（本次新增需求）

> 参照 TBH：背包是**方格网格**（稀有度边框色一眼读懂），点击格子弹出**详情+操作聚合**的弹窗，
> 库存/编队分页各管一类对象。我们现状是"一行一件"的列表，信息密度低、长列表滚动疲劳。

#### 3.3.1 背包：网格 + 分类页签 + 堆叠

- **网格布局**：方格槽位自适应排布（每格 ~44px，一屏可见 20~30 件，不再一行一件占满整行）；
  格子 = 物品图标 + 品质边框色（普通灰 / 精致蓝 / 稀有金）+ 右下角数量角标；
- **同名同品质堆叠**：背包条目从 `{it, q}` 升级为 `{it, q, n}`（上限 99），使用/出售消耗数量，
  归零移除——网格密度再翻数倍，迁移时旧条目按 n=1 处理；
- **分类页签**（按用途，TBH 库存/编队分页的同构）：

| 页签 | 包含（按 effect.kind） | 物品 |
| --- | --- | --- |
| 全部 | — | 全部 |
| 礼物 | send_gift / send_favor | 礼物盒、限量藏品、纪念品 |
| 消耗 | stamina / favor_random / favor_all / rep | 体力咖啡、奶茶券、蛋糕、内部简报 |
| 票券 | free_date | 手写请柬、双人展票 |
| 功能 | buff_date / buff_attr / unlock_next | 名片夹、画册、引荐名片 |

- **点击格子 → 详情弹窗**（操作聚合，替代现在"使用…"直接二跳）：大图标 + 名称/品质/完整效果/售价/**来源**（资产掉落·约会惊喜·NPC回礼）+ [使用] [送出] [出售] 按钮；需要目标的送出类在弹窗内二次选人；
- **悬停 tooltip**：一行速览（名称 + 主效果 + 售价）。

#### 3.3.2 名册：网格卡片 + 状态分类

- **网格卡片**（每张 ~180px，自适应 2~5 列）：头像 + 名字 + 类型/tier 角标 + 迷你好感条 + 阶段角标；
  不再一行一张占满整宽；圈层分组头保留（T1~T5 分节）；
- **点击卡片 → 详情弹窗**：档案卡六行 + 消费菜单 + 渠道按钮整体迁入弹窗（替代现在的行内展开区），
  弹窗内操作后原地刷新不关窗；
- **状态分类页签**：全部 / 可攻略 / 攻略中 / 人脉资产 / 已引荐（跨圈层筛选，配合圈层分组头双维定位）；
- **bar 舞台联动**（承接上文）：bar 上 NPC 悬停气泡与点击行为不变，点击后打开的攻略页按当前页签定位并弹出该 NPC 详情。

#### 3.3.3 实现口径

- 悬停气泡/tooltip 用全局轻量 div 组件（跟随鼠标，数据源 dossier/items），不做 canvas 内绘制；
- 网格用 CSS grid `repeat(auto-fill, minmax(Npx, 1fr))` 自适应任意 bar 宽度（含 1/5 迷你态）；
- 堆叠改造涉及 `invAdd/useItem/sellItem` 三处引擎函数 + 迁移，是 §3 里唯一动存档结构的点，需重点回归。

### 3.4 验收

- 默认安装首次启动即为 1/5 宽、贴右下（TBH 同款角落位）；
- 宽度调节顺滑、重启保持；1/5 宽下 HUD 不溢出、槽位可滚动查看全部；
- bar 上悬停任意 NPC 300ms 内出气泡；背包悬停/点击均可见完整介绍；
- 背包与名册均为网格布局 + 分类页签；同名物品堆叠计数正确，使用/出售扣减数量；
- 拖拽挪动 + 四边吸附 + 面板方向自适应；多显示器不越界；托盘可一键重置位置。

### 3.5 成本

约 4~5 天：main.js 窗口管理重写（宽度/锚点/拖拽）+ ui-bar 响应式分档 + 悬停组件
+ 背包/名册网格与分类 + **堆叠模型迁移（存档结构变更，重点回归）**。
是本草案最大的一块，**建议单独立项**，并保留 v2 全宽形态作为回归对照。

## 4. 背包空间答疑与扩容方案

**现状**：上限 50（`LOOT.INV_CAP`），满了优先挤普通（同品质挤最旧），稀有永不自动消失。

**掉落压力测算**：中期 5 资产 × 平均 200 秒/次 × ~25% 物品分支 ≈ **20+ 件/小时**，约 2.5 小时挂满；
决策器会消耗咖啡/礼盒/蛋糕但不固定，纯挂机党必然顶满。

**结论：需要扩，但「合成 + 金币坑扩容 + 自动出售」三件套比单纯改大数字更健康**：

| 手段 | 说明 | 定位 |
| --- | --- | --- |
| 合成 3→1 | 见 §1，等效容量 ×3 | 消耗出口（主） |
| 背包扩容 | 5万 / 50万 / 500万 金 → 60 / 70 / 80 格（TBH 卖仓库位的金币坑版） | 金币坑 + 玩家选择 |
| 自动出售 | 见 §4.1，按品质阈值拾取即售 | 挂机党兜底 |

### 4.1 自动出售：品质阈值制（该档及以下）

**设置项**：`autoSellGrade`，三档单选（设置页·界面与通知组）：

| 选项 | 语义 |
| --- | --- |
| 关闭（默认） | 现行为：全部入包，满包挤普通 |
| 普通及以下 | 拾取时普通品质直接折价出售 |
| 精致及以下 | 普通+精致均直接折价出售（稀有仍入包） |

- **档位序**：普通 < 精致 < 稀有；最高只提供到「精致及以下」（全卖没有意义，不提供稀有档）；
- **触发时机**：拾取瞬间结算——在线掉落与离线包裹同口径，≤阈值的物品不进背包，直接按 30% 折价入账；
- **播报**：拾取浮字改为「自动售出 XX +N」（`notifyLevel` 静音时不 toast，浮字保留）；
- **与合成的关系**：刻意互为取舍——开「普通及以下」会饿死 §1 的合成（普通件攒不起来），玩家按玩法自选；默认关闭保持现行为；
- **与满包挤占的关系**：两机制并行，阈值过滤在前、满包挤占兜底在后；
- **决策器无感**：它只消费背包内物品（咖啡/礼盒），阈值不影响 AI 行为；
- **迁移**：旧档无此键按 `off` 处理。

**验收**：三档切换即时生效；离线包裹同口径折算（金币进 packGold）；「精致及以下」下稀有必入包；合成在「普通及以下」开启时确实攒不起普通件（符合预期取舍）。

## 5. 物品掉落时机（当前实现口径，答疑存档）

1. **人脉资产周期掉落**（唯一常规来源）：只有满级 NPC 掉；间隔 = 层基准（T1 120s / T2 150s / T3 240s / T4 420s / T5 720s）÷ 个体系数 × 后台倍率 × random(0.7~1.3)，声望型 ×2；掉什么按类型分流（金钱型 70% 金币包 / 辅助型 65% 物品向 / 声望型 55% 手札+20% 情报）；**攻略中的 NPC 不掉**（产出即好感进度）；
2. **约会「惊喜时刻」**：事件表 5% 权重（命中偏好/热点翻倍），掉 1 件普通物品；
3. **NPC 回礼**：大礼/远行/办事结算后 8%，品质 +1 档，每 NPC 每游戏周限 1 次；
4. **离线包裹**：离线期间掉落按期望折算，回归简报一次性收取。
