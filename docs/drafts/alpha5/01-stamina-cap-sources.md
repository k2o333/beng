# 01 · 体力上限来源迁移：成就 → 技能 / 宝物 / 宠物

> **一句话**：把「体力上限」从成就被动里拿掉，改由三个 Build 系统供给——技能（天赋网）、宝物（装备）、宠物（三阶）。
> 状态：草案，待拍板后实施。工作量 ≈1 天（纯数据表 + 1 件新装备 + 1 只新宠物，零引擎结构改动）。

## 1. 问题

现状（alpha4 实装）：体力上限 = `staminaMax(100) + 成就词条`，来源是**人脉广博 +20 / 人脉广博II 再+10**（上限 130）。

不合理之处：

1. **来源错位**：其余四条成就被动都是本循环的乘区（互动→好感、上班→时薪、拾取→掉落、约会→约会价），唯独人脉广博发的是与「人脉」无关的体力上限——成就被动应是「该玩法玩得好→该玩法更强」的身份奖励，体力上限是 Build 维度不是成就维度；
2. **不可经营**：成就是一次性达成即永久，玩家无法通过Build选择去「要或不要」这条体力；而体力上限天然是技能/装备/宠物的词条语言（可搭配、可取舍）；
3. **II 阶放大尴尬**：+20/+10 的「再+一半」规则在 flat 词条上只是凑数（alpha4 S5 顺带产物），没有独立设计价值。

## 2. 目标方案

体力上限来源迁移表（上限口径：基准 100）：

| 来源 | 现状 | 改后 |
| --- | --- | --- |
| 成就·人脉广博 / II | +20 / +10 | **移除**，换成身份被动（见 §2.1） |
| 技能·兼职达人 c14 | 无词条（×2 工资/耗体硬编码） | **追加 stamMaxAdd flat +20**（打两份班的人，精力上限更高——零树结构改动，主题自洽） |
| 宝物·装备 | 仅手表(时薪)/首饰(好感)两槽两件 | **新增第三槽「手环·活力向」**：体能手环 🟢，体力上限 +15（基准），精致 ×1.5 / 稀有 ×2，仅掉落获取（同现有装备口径） |
| 宠物 | 三只各三阶，无体力词条 | **新增第四只「伙伴·活力 🐹」**：stat `totalInteract`，三阶 500/1500/5000 次 → 体力上限 +10 / +15 / +20 |

改后上限区间：**100 ~ 170**（原 100~130）；体力回复速率（12/分）不动——上限只影响「存量/爆发/离线回满存量」，不加速任何循环，通胀风险低。

### 2.1 人脉广博 / II 的替换被动（待拍板二选一）

| 选项 | 效果 | 理由 |
| --- | --- | --- |
| A（推荐）· 人情往来 | 回礼概率 8% → **+2pp / 再+1pp**（即 10% / 11%） | 人脉广→人情往来多，身份贴切；概率词条不进乘区、不复合放大；实现为 `DATE.RETURN_CHANCE + flat词条`（engine 一处读表点） |
| B · 引荐人脉 | 引荐名片类物品效果强化：解锁目标好感门槛相关 | 语义也通，但引荐链本身已自闭合，收益感知弱 |

### 2.2 第三槽「手环」——重开 03 §3 否决项的说明

alpha4 曾否决「装备第三槽」，理由是「毕业感根因是可达性不是槽数，S3 pity 解决后再议」——该前置已满足（pity 落地、稀有装备 ETA 总裁前可达）。本次重开的理由不同：**体力上限需要一件身份明确的载体**，塞进手表（收益向）/首饰（社交向）都会污染既有槽位语义。风险可控：手环只带 staminaMax 单词条，不与另两槽竞争 Build 强度。

## 3. 存档与兼容

- **零版本号升级**：成就被动由 ACHIEVEMENTS 表派生（旧档 `perks` 不动，效果自动切换）；宠物白名单按 `BALANCE.PETS` 过滤（新宠物旧档自然缺席，可正常解锁）；技能节点按 id 追加（c14 加词条对已点亮者自动生效）；装备槽校验按 `effect.slot` 白名单（新增 slot 值 'band' 需同步 normalize 白名单与 ui 装备区——唯一一处小改）；
- 已达成 networker 的旧档会**立即失去** +20/+10（预期行为，发布说明写明）。

## 4. 验收基线

1. `npm test` 全绿；新增断言：c14 词条注册、体能手环穿卸与品质放大、活力仓鼠三阶、networker 新被动（回礼概率生效）、装备槽 'band' 校验；
2. sim quick 回归：体力上限变化不推动时刻表出窗（上限不加速循环，预期无影响，照跑确认）；
3. 红线自查：无数值付费 ✅ / 掉率透明（手环掉率公示口径沿用装备）✅ / 无随机失败 ✅。

## 5. 明确不做

- 不动体力回复速率与互动耗（行动经济刚校准过，§21 alpha4 基线）；
- 不给手环加第二词条（保持单身份）；
- 不做「体力上限」类付费/广告口（红线 3）。
