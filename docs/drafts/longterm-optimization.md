# 长期优化备选池（源自 TBH 调研）

> 从《TBH: Task Bar Hero》借鉴清单中筛选出的三项**长期优化候选项**。
> 调研全文见 `../research/tbh-reference.md`；高优先的合成/成就层见 `next-iteration.md`。
> 状态：备选，未排期。每项含验收标准，排期时直接拆任务。

## 1. 条上 ×1/×2/×4 时间流速快捷键（源自 TBH 常驻速度键）

**问题**：`timeScale` 藏在 设置→管理后台→时间组 两层面板深处；想临时加速（如验证数值、午休挂机）成本过高。

**方案**：
- HUD 收入行旁加一枚小按钮，点击循环 ×1 → ×2 → ×4 → ×1；
- 点击写入 `settings.timeScale`，但**不标记 customMode**（定位为便利功能而非导演模式参数）；
- 管理后台仍可精细调节（0.5~5.0），条上快捷键只是常用档位的快捷方式；
- 按钮上常显当前倍率（×1 时弱化显示）。

**验收**：不打开面板的情况下 1 次点击完成变速；变速后掉落/冷却/工资同步变化；存档重载后保持。

**成本**：约 20 行（ui-bar HUD + app action）。

## 2. 掉落稀有度光效 + 获得播报（源自 TBH 稀有度边框语言）

**问题**：掉落物图标无品质差异，稀有掉落的"哇"时刻被浪费；TBH 用边框颜色让玩家一眼读懂价值。

**方案**：
- 掉落物绘制时按品质加底部光晕：普通无 / 精致蓝 `#7ab8ff` / 稀有金 `#ffd76a`（与背包 qtag 同色系）；
- 稀有品质落地时条上方横幅播报一次（复用 toast：「💎 掉落稀有物品：限量藏品」）；
- `notifyLevel` 为 mute 时播报静默，光效保留。

**验收**：三种品质掉落物视觉可区分；稀有落地必有播报；静音模式下无 toast 但光效在。

**成本**：约半天（ui-bar 掉落绘制 + eventFx 分支）。

## 3. 离线宝箱具象化（源自 TBH 宝箱充能→弹出）

**问题**：离线收益目前是纯文字弹窗，缺少 TBH 那种"宝箱在条上充能、回来点开"的仪式感。

**方案**：
- 回归时（离线结算有产出时）条上落一只宝箱，落点为屏幕中偏右固定位；
- 宝箱带充能条 = `min(1, 离线游戏时长/离线上限)`，充能满有金光呼吸；
- 点击宝箱 → 开包动画 + 现有离线简报弹窗弹出（简报内容不变，只是多了实体入口）；
- `autoPickup` 关闭时宝箱不自动消失，必须手点（保留主动摸鱼的甜头）。

**验收**：离线 ≥5 分钟回归必见宝箱；点击后简报弹出且包裹入包；宝箱未点时不重复生成。

**成本**：约半天（复用 drops 视觉管线 + settleOffline 报告标记）。

## 排期建议

三项相互独立，可任意拆分；若只做一项，优先 **1（速度键）**——成本最低、日常使用频率最高。
