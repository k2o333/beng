# 03 · 职业与业务系统

> 口径源：`career-numbers-mini.md` §1/§2/§4。打工线先上，创业线后置（依赖三维关系）。

## 跑单管线（放置期自动 / 操作期可换单）

```mermaid
flowchart TD
    TICK["周期 tick / Agent L2 检查"] --> HAS{"当前有业务单？"}
    HAS -->|"无"| PICK["从模板池筛选<br/>按圈层解锁 + 职级要求"]
    PICK --> EFF["效率 = min(人脉A比, 人脉B比, 类型计数比, …)<br/>不足时 UI 明示缺口"]
    EFF --> RUN["开跑：工时 = 基准 × bizSpeed 旋钮"]
    HAS -->|"有"| PROG["进度推进（离线照跑）"]
    PROG --> DONE{"进度满？"}
    DONE -->|"否"| PROG
    DONE -->|"是"| SETTLE["实得业务量 = 基准 × 效率<br/>金币 = 基准 × 提成率 × 圈层修正 mult^0.5"]
    SETTLE --> PROMO{"累计业务量 ≥ 下级门槛？"}
    PROMO -->|"是"| UP["升职 +1：<br/>提成率↑ / 津贴↑ / 技能点+1 / toast"]
    PROMO -->|"否"| NEXT["回 PICK 接下一单"]
    UP --> NEXT
```

## 业务单状态机

```mermaid
stateDiagram-v2
    [*] --> 空闲
    空闲 --> 选单: Agent L2 或 手动换单
    选单 --> 进行中: 效率折算后锁定工时
    进行中 --> 进行中: 周期 tick 推进
    进行中 --> 结算: 进度满
    结算 --> 空闲: 业务量入账 / 提成发放
    结算 --> 升职检查: 门槛达成
    升职检查 --> 空闲: level+1 发技能点
```

## 打工 / 创业双模式（同表不同分成）

```mermaid
flowchart LR
    MODE{"careerMode 旋钮"}
    MODE -->|"打工（首版）"| EMP["借公司平台跑单<br/>分成 ≈6.5% 中位 + 津贴<br/>门槛看人脉"]
    MODE -.->|"创业（后置）"| FOUNDER["自己组织业务<br/>分成 65% ≈ 打工×10<br/>门槛看信任/价值感（三维关系）"]
```

## 备注

- 业务量是进度量纲（万），不消费；金币仍是唯一货币。
- 首版模板池 ~12 条（每圈层 3~4 条）；全部参数进 SETTINGS_DEFAULT。
