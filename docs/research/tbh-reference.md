# TBH: Task Bar Hero 调研 —— 可借鉴要素分析

> 调研对象：《TBH: Task Bar Hero（塔斯克巴·英雄）》，Nugem Studio（首尔，2人团队），2026-05-27 上线，F2P+DLC。
> 峰值 23 万同时在线；国区好评率曾从 88% 跌到 30%（爆率+外挂+市场崩坏），全球长期 Mixed 62%。
> 本项目（人脉圈）与其同属"任务栏常驻像素放置"赛道，且 07 掉落文档原本就标注了"TBH 式桌面掉落反馈"。

## 1. 它是什么（画面实证）

- **任务栏本体**：整个游戏压缩成贴在 Windows 任务栏上的一小条（约 100px 高），
  像素小人从左向右推进自动打怪，头顶血条，宝箱带充能进度条从天而降，右端一小簇控制按钮（药水/关卡/功能）。
- **升起式面板**：点击功能按钮，一块高面板从条上"长"出来——哥特金属雕花边框 + 红色缎带标题 + 金铜配色；
  可多面板并排停靠（STATUS / 英雄装备 / PORTAL 传送门三开）。
- **装备页**：人像四周环绕装备槽，背包网格用**边框颜色表达稀有度**（白/绿/蓝/紫/…最高"宇宙级"共 10 档）。
- **技能树**：按角色等级分 0/10/30 三档解锁，技能点分配。
- **传送门**：Act 1~3 章节页签 + 难度下拉 + 世界地图节点（2-1~2-6，旗子标当前进度）。
- **掉落播报**：条上方浮出"Obtained Iron Helmet"横幅。
- **成就文案全是摸鱼梗**："I Was Just Idling..."、"Still Not Off the Clock"、"Hell? Better Than Monday."

## 2. 玩法骨架

| 系统 | 内容 | 商业化 |
| --- | --- | --- |
| 自动战斗 | 派遣勇者自动推图，玩家只在**开箱/重置关卡/升级**时干预（"干预式"交互） | 免费 |
| 装备 | 500+ 道具、10 档稀有度、魔方系统（自定义词条）、**9 件同稀有度合成 1 件更高** | 市场交易抽成 |
| 宠物 | **永久账号级全局被动**（金/经验/宝箱 %，可无限叠加），靠"击杀 5000 只 X"解锁，DLC 宠物直接卖 | 18 元礼包 |
| 关卡 | 3 章 ×4 难度，刷-重置循环 | —— |
| 交易 | 掉落物上 Steam 市场换真钱 → 引爆增长也引来工作室/外挂，服务器与经济双崩 | 教训案例 |
| 氪金点 | 支持者礼包（约 18 元）、仓库位、付费职业、交易船 | 克制小额 |

## 3. 对人脉圈的可借鉴清单（按价值/成本排序）

### A. 强烈建议做（玩法增益大、实现成本低）

1. **物品合成（3 合 1 升品质）**
   - TBH 用 9 合 1 解决"垃圾掉落无处安放"；我们有同构问题：普通物品泛滥、稀有物品无用武之地。
   - 方案：背包页加"合成"按钮，3 件同品质 → 1 件随机高一档品质（普通→精致→稀有）。
   - 成本：约 60 行（engine.synthItems + 背包页按钮），复用 qualityRank。

2. **全局被动成就层（"摸鱼成就"）**
   - TBH 宠物 = 永久叠加的账号被动，是长线留存的钩子。我们的辅助型资产已有 +5% 全局好感同构，
     缺的是**资产之外的账号级成长**。
   - 方案：累计互动 1000 次→全局好感 +3%；累计上班 100 小时→时薪 +10%；累计掉落 500 件→掉落间隔 -5%……
     成就即被动，文案走摸鱼自嘲风（对齐 TBH 的 "Hell? Better Than Monday" 味道）。
   - 成本：计数器已在 stats 里，加成就表 + 检查函数 + 设置页展示，约半天。

3. **条上 ×1/×2 时间流速快捷键**
   - TBH 把速度控制常驻在条上。我们 timeScale 藏在管理后台深处，日常想加速要开两层面板。
   - 方案：HUD 加一枚小按钮循环 ×1/×2/×4（写 settings.timeScale，customMode 不标记——这是便利功能不是作弊）。
   - 成本：约 20 行。

### B. 值得做（体验增益中等）

4. **稀有度光效与获得播报**
   - TBH 的稀有度边框色是"一眼读懂"的语言。我们的掉落图标目前无品质差异。
   - 方案：掉落物按品质加描边光（普通无/精致蓝/稀有金）；获得稀有物品时条上方横幅播报一次。
   - 成本：ui-bar 掉落绘制加 2 行 fillRect 光晕 + 复用 toast。

5. **离线宝箱具象化**
   - TBH 宝箱"充能→弹出"的期待感很好。我们的离线包裹目前是纯弹窗。
   - 方案：回归时条上落一只宝箱（充能条=离线时长占比），点击开包（替代或叠加现有简报弹窗），保留开箱爽感。
   - 成本：复用 drops 视觉管线 + 简报数据，约半天。

### C. 观望/不做

6. **多面板并排停靠**——我们的面板是 420px 单列，双列在笔记本上会挤；二期再说。
7. **交易/市场**——TBH 的差评轰炸核心教训：开放交易 → 工作室刷爆经济。我们是单机游戏，永不开放。
8. **关卡重置刷宠**——我们的 NPC 是一次性攻略对象，无重置语义；"刷"的需求由掉落系统承担。

## 4. 值得抄的运营/文案细节

- 成就命名走"打工人共鸣"路线（参考 TBH：上班摸鱼梗），与本项目"清醒体面向上"基调兼容。
- 小额克制付费：若将来上 Steam，支持者礼包（外观/仓库位）而非数值付费——TBH 的 Butterfly（付费弱于免费）被喷是反面教材。
- 掉率透明：TBH 差评核心是"爆率黑箱+突然削落率"。我们 06 待校准清单坚持"期望对齐、后台可调、档案卡公示掉落口径"是正确方向，应坚持。

## 5. 结论

TBH 验证了本项目赛道的产品形态（任务栏条 + 升起面板 + 干预式放置），我们的骨架已对齐；
真正值得吸收的是三件事：**合成消化垃圾掉落、账号级被动成就层、条上速度快捷键**（A 组），
其次是稀有度视觉语言与离线宝箱的"开箱仪式感"（B 组）。
