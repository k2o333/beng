## 1 · H1~H6 逐条判定

### H1 收入后期单边倾斜 —— 结论：**部分证实，校准后已控住**
- 数据：校准前 `docs/reports/sim-summary-20260826.md`（03:43 版）§2：drops 77% / biz 22%；校准后 `sim-standard-20260826.json incomeLateP50Share`：**biz 83.2% / drops 16.3% / 售物 0.5%**，五策略 `H1 判定行`全部「未独占」（<90%）。
- 动作：dropValueRate 1→0.08 + dropIntervalRate 1→2（掉落降为副泵）；CAREER_LEVELS.allowance 高段削减 60~80%（津贴按结单周期发放，在单流量下会反超提成）。
- 残余风险：biz 占比已 83%，任何进一步削弱业务或掉落的调参都可能越 90% 线；建议后续版本给工资/小费一条成长曲线作为第三泵。

### H2 稀有装备可达性 —— 结论：**证实（pity 前），S3 保底后总裁前可达**
- 数据：`balance.md §C/H2 核验`：自然概率 P/drop = 10%×1.0×8%×3% = 2.4e-4 → 期望 4167 掉落；T3 起 ≥277.78 游戏时。
- 新速率解析（dropIntervalRate=2 后）：T1 单资产 ≈17.2 掉落/时；PITY_EQUIP=120 次 func 分支 ≈1200 总掉落 ≈ **70 游戏时/资产必出装备（≥精致）**；PITY_RARE=240 件物品再兜稀有品质。多资产并行下稀有装备在总裁（d49.6）前稳定可得。sim 旁证：`avgRareEquipPerRun = 492.66`（R=80）/百日。
- 残余风险：保底产出的是「装备位」而非「稀有装备位」，理论最坏组合仍需 ~2400 掉落；后台调 equipDropRate/rareItemRate 时两处 pity 不联动，需人工复核。

### H3 T3→T4 门槛死区 —— 结论：**证实三重跳存在，实测非死区**
- 数据：`balance.md §E`：T3→T4 rep ×3.75 / fee ×15 / taste +15 三跳并存；sim `deadZones`：**T3→T4 停留 P50=12.67 日 < 上限 30** ✓（T2→T3 7.60 < 14，T4→T5 19.17 < 60 同过）。

- 残余风险：死区消失是因为品味变便宜，若未来回调 ATTR 曲线需同步复测本行。

### H4 errand 性价比倒挂 —— 结论：**证实倒挂，限次兜底有效**
- 数据：`balance.md §B`：errand gpf 13200（T1）vs 最优约会轻约 8×1.2×0.35≈3.36 好感/360 金≈107 gpf——倒挂仍在但每人限一次；sim `avgErrandPerRun = 0.1`（R=80），不构成主导策略 ✓。
- 残余风险：无。若日后放开限次，需先重定价。

### H5 属性指数成本弃坑点 —— 结论：**通过（弃坑点晚于 T3）**

## 3 · D-revision 提案

### D6 · 宠物·暖手三阶目标二修 —— **已按预案应用，⚠ 待拍板追认**
- 结构性证据：`totalDates` 只在 `engine.spendDate`（付费约会）自增；邀约免单与物品免单走 `resolveDate` 不计数。可付费约会池受三重钳制：①价格×favorPerYuanRate(0.35) 后只有 T1/T2 档能进 perNpcBudget；②NPC 转资产后窗口永久关闭（名册 30 人单向耗尽）；③预算内大礼评分(250)长期挤占约会。
- **终版实测曲线**（校准定稿后 standard R=12，sim 内置 datesCurve 追踪）：`totalDates` P50 = d15 23.5 → d30 24.0 → d60~100 平台 24.5。即**前期 ~5 次/日冲到 ~24 次后因名册资产化饱和而平台化**——2000（乃至一阶 200）在任何 data-only 配置下不可达；把 III 抬到 30+ 则永不达成（比早达成更差）。唯一暴力通路（favorPerYuanRate≈0.05 逼玩家百次约会换一人）会摧毁送礼/约会经济与 lavish 流派语义，已评估并放弃。
- 处置：stages 定标 {8, 16, 24}（III 实测 P50 ≈ d5 达成，早于原 60~90 日锚——平台化根因下「锚定 60~90」与「可达」不可兼得，取可达；I→II→III 复利曲线与阶段词条仍完整可见）。
- **待拍板**：①追认新阈值；②是否接受「暖手对 frugal 流派不可达」「III 早达」；③alpha5 结构提案（根治平台化，让 60~90 锚定成立）：资产「回忆约会」/高圈层 NPC 分批入场/INVITE 免单计入 totalDates（engine 一行改动）。

### D7 · 成就二阶目标重定标 —— **仅提案，未应用（ACHIEVEMENTS 表不在本轮授权范围）**
- 证据：全成就 0%/20 五策略皆然（quick 报告 §1）。卡点三项：`touch` 互动 1000（trace 实测百日 interacts ≈355，官方 agent 行动经济下不可达）、`social2` 约会 500（同 D6，上限 ~36）、`touch2` 5000（同 touch）。
- 建议：touch 1000→300、touch2 5000→1200、social 100→25、social2 500→60（其余成就 workaholic/picker/networker 系在现速率下均可达，不必动）。
- 影响预估：全成就日将主要由 networker2（25 资产，现速率 d60~75 可达）与 workaholic2（500h，d70±）决定，落在 60~90 目标带内——待采纳后跑 sim 复核。
